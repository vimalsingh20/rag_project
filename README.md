# 🚀 RAG PDF Chatbot

A scalable Retrieval-Augmented Generation (RAG) application that allows users to interact with PDF documents through natural language questions. The project integrates semantic retrieval (FAISS), keyword retrieval (BM25), and Google's Gemini LLM to provide relevant and context-aware responses.

Designed with a production-oriented architecture using FastAPI, Streamlit, MySQL, and Sentence Transformers, the system includes per-document vector indexing, document caching, active document management, structured logging, and comprehensive error handling for improved reliability and maintainability.
